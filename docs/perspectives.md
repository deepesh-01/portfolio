## How To Read The Rest Of This Site

Toggle the **perspective switcher** in the nav. The pages don't change —
the *weight* changes. Founder mode highlights the business decisions.
Engineer mode highlights the technical ones. Human mode lets the raw
narrative breathe. Default mode shows everything equally.

This is the same map at three zoom levels — pick the one your context
needs.
